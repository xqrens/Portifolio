01 / Contexto

Tornar assuntos importantes mais acessíveis.

O objetivo foi reunir informações de saúde mental em uma interface acolhedora, sem fazer promessas de diagnóstico, tratamento ou acompanhamento profissional.

02 / Solução

Uma experiência que não exige pressa.

O site distribui práticas, pausas, recursos e informações de apoio em seções claras, com navegação e linguagem cuidadosas.

03 / Implementação

Design, semântica e interações.

O projeto utiliza HTML semântico, CSS responsivo, JavaScript para interações da página e respeito à preferência por movimento reduzido. A organização é pensada para leitura em diferentes dispositivos.

04 / Aprendizados

O conteúdo deve orientar o desenho.

Neste trabalho, clareza, contraste, tom da escrita e acessibilidade foram tão importantes quanto as animações. O projeto continua sendo educativo, não um serviço de saúde.

Este estudo de caso relata funcionalidades e decisões técnicas do projeto, sem métricas inventadas ou promessas de experiência profissional na área.
