01 / Contexto02 / Solução03 / Implementação04 / Aprendizados
01 / Contexto

Aprender JavaScript fazendo.

A proposta foi criar uma ferramenta simples que permite experimentar combinações de cores, com foco em eventos do navegador e estado de interface.

02 / Solução

Cinco cores com controle.

O usuário pode gerar uma paleta, travar os tons favoritos e copiar os respectivos códigos HEX. As cores travadas permanecem em novas combinações.

03 / Implementação

Pequenas funções, comportamento claro.

A lógica transforma valores HSL em hexadecimal, organiza estados de bloqueio por índice e utiliza textContent para atualizar elementos com segurança. O armazenamento local tem tratamento de erros.

04 / Aprendizados

O usuário precisa entender o estado.

Não basta gerar cores: as ações devem indicar claramente se algo está travado, se foi copiado e o que aconteceu após cada clique.

Este estudo de caso relata funcionalidades e decisões técnicas do projeto, sem métricas inventadas ou promessas de experiência profissional na área.
